# mai-video-adaptive

麦麦视频理解的自适应抽帧模块。

把视频按「内容信息密度」自适应抽帧，交给视觉模型理解，把成本压在分币级、把耗时压在秒级。

## 流程

1. **探测**：ffprobe 读时长 + 每个 packet 的字节数（码率数据）
2. **侦察采样**：全片均匀抽 32 张小缩略图（本地抽帧，零 API 成本）
3. **算指标**：
   - 新颖率：缩略图去重后剩余比例，专治「重复内容」
   - 码率波动：密度曲线起伏，辅助判断
4. **定帧数区间**：时长给基础上下限 → 新颖率缩放 → 全局硬上限兜底
5. **排布帧位**：按码率密度曲线做 CDF 撒点（密处密、疏处疏）
6. **抽帧**：ffmpeg 按时间点逐点抽，等比缩小
7. **指纹去重**：探针帧算图像指纹，命中缓存则复用旧描述，跳过 API
8. **交模型理解**

一句话分工：**新颖率管「抽几张」，密度曲线管「抽在哪」，指纹管「要不要重抽」。**

## 依赖

- `ffmpeg` / `ffprobe`（需在 PATH）
- Python 3.10+

## 参数

| 参数 | 默认 | 说明 |
|---|---|---|
| min_frames | 8 | 帧数下限（保底信息） |
| max_frames | 24 | 帧数上限（封住成本） |
| seconds_per_frame | 5.0 | 时长 → 基础帧数的基准 |
| bucket_s | 0.5 | 密度曲线的分桶粒度 |
| max_height | 720 | 抽帧后的最大高度 |
